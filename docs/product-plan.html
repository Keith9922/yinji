1产品定位与愿景

印迹 = 照片 × 印章风格化 × 手账收集

用 AI 将照片变成印章贴纸，像集邮一样收集你的生活印迹。

核心理念

用户旅行或日常生活中拍摄的照片，经过 AI 风格转换后变成独一无二的"印章"，可以收藏在数字手账中，按地点、时间、主题组织，形成个人专属的印迹地图。

目标用户

用户群体核心需求使用场景
旅行爱好者记录每个去过的地方到景点拍照 → 生成该地印章 → 收入旅行集
手账/文创用户独特的装饰素材生成印章 → 导出透明PNG → 用于手账排版
生活记录者日常生活的仪式感美食、宠物、孩子的照片 → 印章化留存
社交分享用户个性化内容创作印章拼贴 → 分享到朋友圈/小红书

3印章生成流水线（升级版）

在现有 Demo 流水线基础上，App 版本增加形状裁切和文字叠加步骤：

1

AI 风格转换 远程 API

原图 + 风格提示词 → Gemini 生成黑白印章风格图。支持 10+ 种风格提示词模板。

2

对比度增强 本地处理

直方图拉伸 + 对比度增强，让线条更锐利分明。与 Demo 版相同。

3

智能抠图 本地处理

rembg 去除背景，输出 RGBA 透明 PNG。App 可将此步移至服务端加速。

4

形状裁切 新增

应用用户选择的印章形状遮罩：圆形、方形、椭圆、邮票齿边等。使用 alpha 通道 mask 实现。

5

印泥上色 本地处理

深色像素替换为目标颜色，浅色像素透明。保留亮度层次模拟浓淡效果。

6

纹理叠加 新增

叠加印泥纹理/磨损效果/纸张纤维，增加真实感。可选做旧程度。

7

文字排版 新增

在印章边缘或中央叠加文字（地名/日期/自定义），支持环形排列、竖排等。

数据流概览
📷 原始照片 → 🤖 Gemini 风格化 → 📈 对比度增强 → ✂️ 背景去除
→
💾 保存到集册 ← ✍️ 文字叠加 ← 🧱 纹理做旧 ← ⭕ 形状裁切 + 上色

5完整用户操作流程

核心流程：拍照 → 生成印章 → 收入集册

打开 App → 点击 ⊕ 按钮 → 拍照 / 选图
↓
选择风格 → 选择形状 → 选颜色 → 添加文字（可选）
↓
点击「生成」 → ⏳ 等待 AI 处理 ~25s → 预览结果
↓
切换其他风格预览 → 选择满意的版本 → 💾 保存到集册

分支流程

分享印章印章详情 → 分享 → 选择模板卡片 → 生成分享图 → 保存/发送

管理集册集册页 → 长按拖拽排序 / 新建集册 / 编辑封面
重新编辑印章印章详情 → 编辑 → 修改颜色/形状/文字 → 保存新版本（保留原版）

7开发路线图

已完成
Phase 0 · 概念验证 Demo
Gradio Web Demo，验证 AI 印章生成核心流水线可行性。4 种风格，6 种颜色，透明 PNG 输出。

扩展印章风格（10+种）、形状裁切、文字叠加、印泥纹理。搭建后端 API 服务，完成移动端基础框架。

App v1.0 · 核心体验
印章生成 + 集册管理 + 印迹地图 + 导出分享。覆盖核心用户旅程，完成首轮用户测试。

App v2.0 · 体验升级
一键多风格预览、时间轴、模板库、分享卡片生成器、成就系统。提升留存和使用频次。

App v3.0 · 社交与生态
社区广场、印章互赠、每日主题打卡、创作者入驻（设计师上传模板）。
